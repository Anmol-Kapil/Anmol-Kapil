### 📦 Predictive Shipment Delay Analytics

**PySpark · Spark SQL · FastAPI · React · scikit-learn · SHAP · HDFS · Docker**

- Processed **181,169 order-item rows** into **62,897 eligible order-level shipment proxies**.
- Built a filterable dashboard for delivery trends, regional analysis, and shipping-mode delay heatmaps.
- Compared Logistic Regression and Random Forest using chronological validation and order-time inputs.
- Achieved **0.7482 ROC-AUC** and **69.46% accuracy** on a chronological test population of **12,631 orders**.
- Added global and individual SHAP explanations with operator review suggestions.
- Integrated optional Groq summaries and validated read-only natural-language-to-SQL queries.

[View Repository](https://github.com/Pranav-github-pixel/Shipment_Delay_Analytics)
